## Format notes

- Top-level `content.json`/`definitions.json` files are complete authored sources, not necessarily direct v1 card imports.
- Per-card JSON files are renderer-compatible v1 cards. Import those into the card editor.
- PDFs preserve readable/selectable text; PNG/SVG files are separate importable visual references.
- A manifest records definitions and card/page counts. Definition totals can differ from the number of split cards or PDF pages.
- Machine-local build probes and redundant downloadable ZIPs are excluded; the sources, galleries and requested outputs are retained.
