# Bellwether: 24 Fate content examples

Original skill-authored demonstration, not campaign canon. **GM edition: contains hidden motives, secrets, mystery answers and antagonist information.** These are bespoke examples made with the Fate Content Generator skill, not outputs of the narrower nine-bundle offline engine.

## Start here

- `Bellwether-24-Fate-Examples.pdf`: 24-page readable showcase, one example per page, selectable text.
- `SHOWCASE.md`: complete copyable text and numbered contents.
- `gallery.html`: standalone offline browser gallery; also printable.
- `cards/`: individual PNG, scalable SVG, plain-text and editable v1 JSON files for all 24 examples.
- `content.json`: complete authored source with content-type labels and mechanical check metadata.
- `manifest.json`: enumerated index, filenames, image dimensions and generation checks.

The deck covers exactly one each: Character, NPC, Creature, Adversary, Location, Faction, Organization, Item, Vehicle, Power, Extra, Aspect, Skill, Approach, Stunt, Scene, Encounter, Mystery, Adventure, Setting, Campaign, Hook, Clue and Random table.

## Rules boundary

Fate Core is the main profile. All invented stunts, powers and extras are original proposals requiring table approval. Chronometry is an optional replacement/split skill-list example, not an additional free skill on the characters. Careful demonstrates Fate Accelerated separately and is never added to a Core roll. The two PC-like skill pyramids and their Core stress derivations were checked programmatically. No encounter is claimed balanced for an unknown party.

Aspects are fictional truths, not automatic numeric bonuses. New permissions, costs and exceptions in the power/extra examples are explicitly homebrew. Factions and locations are statless unless a scenario needs more mechanics. Vehicle operation uses the setting's stated Drive convention, not a second autonomous character turn.

## Verification

The exported set is checked for 24 unique requested types, slugs and titles; each JSON passes the cardmaker's version-1 validation. Each PNG decodes and each SVG parses. Every HTML page was measured for overflow and separation from its footer before PDF export; the PDF contains 24 page objects and its extracted text was spot-checked. Representative graphical cards were visually inspected. See the content review note for any editorial qualifications.

No existing campaign files or game code were changed. JSON cards can be imported into the existing Python cardmaker for editing. Generic card JSON has no trusted public/GM field classification: these GM examples must be redacted deliberately before player sharing. Specific third-party import targets have not been tested.
